# Contributing to the SchoolBrief Roadmap

Thanks for helping improve SchoolBrief.

## Before opening an issue

Please search existing issues first. If the same problem or request already exists, add useful context there instead of opening a duplicate.

## Bug reports

Include:

- what you expected to happen;
- what happened instead;
- the district and school involved, when relevant;
- the approximate date/time you observed it;
- the SchoolBrief app version, when known; and
- a screenshot if it helps explain the visible behavior and contains no private information.

Do not include student information, credentials, private account data, or security-sensitive diagnostics.

## Feature requests

Describe the user problem first, then the capability you would like SchoolBrief to provide. A proposed implementation is welcome but is not required.

## District requests

Name the school district and state. If possible, include the district's official public website. Requests help prioritize expansion but are not commitments to a particular release date.

## Security and privacy issues

Do not open a public issue for a suspected vulnerability or privacy exposure. Follow [SECURITY.md](SECURITY.md) instead.

## Public status

Roadmap status describes what has actually been verified. A source change or passing test does not by itself mean a fix has reached the released app or production service.
