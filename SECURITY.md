# Security Policy

Please do **not** report security vulnerabilities in a public GitHub issue.

If you believe you have found a security or privacy issue affecting SchoolBrief, contact **support@schoolbrief.io** with enough detail for the issue to be reproduced and evaluated privately.

Public roadmap issues are intended for user-visible bugs, feature requests, district requests, and known limitations—not exploit details, credentials, private data, or production diagnostics.
